# S-023 첫 진입 온보딩

## 상태

- 상태: draft
- 구현 여부: not-started
- 검증 여부: not-tested

## 의존성

- S-002 어항 / S-003 이미지 입력 / S-004 물고기 생성
- S-021 마법 모먼트 (가이드 마지막 단계의 보상)
- S-022 사운드 시스템 (음성 안내·소리 가이드)
- S-013 prop-panel (등록 후 자동 오픈)

## 목표

- 글자를 못 읽는 어린이(4–6세)도 첫 진입 60초 이내에 첫 물고기를 등록할 수 있게 한다.
- 텍스트 의존을 최소화하고 **고스트 손가락(Ghost Finger) 애니메이션**으로 다음 행동을 시연한다.
- 어린이가 가이드 외 다른 곳을 만져도 좌절하지 않도록, 어떤 행동도 부드럽게 가이드로 복귀시킨다.
- 부모/재방문 사용자가 가이드를 건너뛰거나 다시 볼 수 있게 한다.

## 범위

- 포함할 것:
  - 5단계 시퀀스 상태 머신
  - Ghost Finger SVG 애니메이션
  - 흐릿한 물고기 윤곽 캔버스 가이드
  - 사용자 일탈 처리
  - 60초 무행동 부드러운 알림 (1회)
  - 부모 영역 "도움말 다시 보기"
  - localStorage 영속
- 제외할 것:
  - 두 번째 이후 진입의 별도 가이드
  - 게임 사용법 문서화 (별도)

## 사용자 흐름

### 시퀀스 0: 사운드 모달 (S-022)
- 첫 진입 시 사운드 모달이 먼저 표시된다.
- 응답 후 시퀀스 1로 진행.

### 시퀀스 1: 빈 어항 환영 (0–4s)
- 빈 어항이 fade-in (1.5s).
- 어항 안 가운데에 점멸하는 큰 "+" 버튼 (88×88px, 1.5s 펄스 주기).
- 옆에 고스트 손가락이 1초 주기로 탭 시연.
- 캡션 옵션: 작게 "물고기를 만들어 보세요".

### 시퀀스 2: 그리기 캔버스 첫 진입 (4–30s)
- "+" 클릭 후 캔버스 모달 fade-in.
- 중앙에 흐릿한 물고기 윤곽 가이드 (opacity **0.25** — 원안 0.15는 4–6세 시지각 대비 너무 옅음).
- 첫 1초간 고스트 손가락이 윤곽을 따라 한 번 그리는 시연.
- 색 팔레트와 그리기 도구에 짧은 펄스 강조 (2회만).
- 사용자가 한 번이라도 캔버스에 터치하면 시연(고스트 손가락)은 즉시 사라진다.
- 단, **윤곽 가이드는 5초간 무입력이면 0.25 opacity로 다시 fade-in** (어린이가 "어떻게 그리지?" 다시 보고싶을 때 회복). 그리기를 재개하면 다시 사라짐.

### 시퀀스 3: 등록 안내
- 그리기 후 5초간 입력 없으면 등록 버튼에 펄스 강조 + 고스트 손가락 시연.
- 이름 입력 비어있으면 자동 이름 (S-004 정책 또는 추천 풀).

### 시퀀스 4: 마법 모먼트 (S-021 통합)
- 등록 클릭 → S-021 자동 재생.
- 마법 모먼트 종료 후 prop-panel 위치를 고스트 손가락이 1회 가리킴.
- 사용자가 prop-panel을 닫거나 어항을 한 번 탭하면 온보딩 종료.

### 시퀀스 5: 종료
- localStorage에 완료 플래그 저장.
- 이후 진입 시 가이드는 표시되지 않는다.
- 부모 영역(설정)에서 "도움말 다시 보기"로 재실행.
- **추가 어포던스**: 어린이 영역의 우상단 모서리에 작은 ❓ 버튼(48×48 hit, 32px 시각)이 항상 표시됨. 클릭 시 가이드 재실행. 4–8세 사용자가 "또 보고싶어"를 부모 호출 없이 직접 만족할 수 있게 함.

## 사용자 일탈 처리

| 상황 | 처리 |
|---|---|
| "+" 외 다른 곳을 탭 | 가이드 무시, 5s 후 가이드 펄스 재개 (최대 3회까지만, 그 후 정적 강조로 전환) |
| 그리기 캔버스에서 닫기 버튼 누름 | 시퀀스 1로 복귀 |
| 등록 없이 캔버스 닫음 | 시퀀스 1로 복귀 |
| 등록 후 prop-panel 즉시 닫음 | 가이드 종료, 정상 사용 모드 |
| **30초간** 아무 행동 없음 | 부드러운 종소리 1회 + 가이드 강조 한 번 더, 이후 무음 대기 (60초에서 단축 — 4–6세 인내 시간) |

## 텍스트 vs 비텍스트

- 모든 가이드 메시지에 이모지/아이콘 우선, 텍스트 부가.
- 텍스트는 14px 이하, 하단에만, 글 못 읽는 어린이는 무시 가능.
- 음성 가이드 옵션 (S-022 활성 시): 시퀀스 1에서 "여기를 눌러봐!" 1회만 (반복 X).
- **음성 가이드 기본값**: 사운드 모달(시퀀스 0)에서 "🔊 소리 켜기" 선택 시 **자동 ON**, "🤫 나중에" 선택 시 OFF. 글 못 읽는 4–6세에게 음성은 가장 직접적인 가이드이므로 사운드를 켰다면 함께 활성화하는 것이 일관됨. 부모 영역에서 별도 토글로 끌 수 있음.

## UI/상태 요구사항

- 필요한 화면 요소:
  - `.onboarding-overlay` (z-index: 40)
  - 점멸 "+" 버튼 (CSS @keyframes pulse, 1.5s)
  - 고스트 손가락 SVG (반투명 흰색)
  - 펄스 강조 ring
  - 그리기 캔버스 가이드 윤곽 layer
- 필요한 상태 (localStorage 저장):
  ```ts
  type OnboardingState = {
    completed: boolean;
    sequence: 1 | 2 | 3 | 4 | 5 | 'done';
    completedAt?: string;
    voiceGuideEnabled: boolean;
  };
  ```
  - localStorage key: `fishbowl.onboarding.v1`

## 안전 가드

- 펄스 애니메이션 빈도 ≤ 2Hz.
- 고스트 손가락 fade는 단조 (깜빡임 없음).
- 60초 무행동 알림은 단 1회.
- prefers-reduced-motion 시 펄스/고스트 손가락이 단순 highlight로 대체.

## UX 리뷰 결정 사항

| 쟁점 | 원안 | 결정 | 근거 |
|---|---|---|---|
| 윤곽 가이드 opacity | 0.15 | 0.25 + 5s 무입력 시 재등장 | 0.15는 4–6세 시지각 한계 미달. 재등장으로 "다시 보고싶어" 충족 |
| 무행동 알림 시간 | 60s | 30s + 가이드 강조 1회 | 4–6세 인내시간 ~30s. 60s는 가이드 손실 위험 |
| 일탈 시 펄스 재개 | 무한 반복 | 최대 3회 후 정적 강조 | 무한 펄스 = 짜증. 인내가 다하면 정적 highlight로 전환 |
| 음성 가이드 기본값 | OFF | 사운드 ON과 연동(켜기 시 자동 ON) | 글 못 읽는 어린이에게 음성이 가장 직접적. 사운드 선택과 일관 |
| 도움말 재실행 어포던스 | 부모 영역만 | 어린이 영역에도 ❓ 버튼 | 4–8세가 부모 호출 없이 자가 회복 |
| "+" 버튼 크기 | 88×88 | 유지 | 첫 진입 강조에 적절 (S-024 어린이 권장 56보다 의도적으로 큼) |

### 충돌/연동 정리

- **S-022**: 시퀀스 0의 사운드 모달 owner는 S-022. 본 스펙은 호스팅만 명시.
- **S-021**: 시퀀스 4 = 마법 모먼트. S-021의 큐 dot 인디케이터는 첫 등록 시 비표시(큐 비어있음).
- **S-013**: 시퀀스 4 종료 후 prop-panel 자동 오픈은 S-013/S-021의 이미 정의된 동작. 본 스펙은 그 위에 ghost finger 1회 가리킴만 추가.
- **S-024**: ❓ 도움말 버튼은 어린이 영역(48×48 hit, 32px 시각). "+" 버튼 88은 의도된 예외(온보딩 강조).
- **S-004 자동 이름**: 본 스펙은 S-004 자동 이름 정책에 의존. 별도 추천 풀을 정의하지 않음.

## SP

**8 SP** — 5단계 시퀀스 머신 + 일탈 처리 + ghost finger SVG 애니메이션 + 윤곽 가이드 캔버스 layer + 펄스/highlight + 음성 가이드 통합 + localStorage + 부모/어린이 영역 도움말 재실행 + S-021/S-022와 깊은 통합. 단일 흐름이지만 통합 대상이 많고 4–6세 회귀 테스트가 까다로움.
