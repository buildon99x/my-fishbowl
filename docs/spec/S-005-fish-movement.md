# S-005 물고기 움직임

## 상태

- 상태: ready
- 구현 여부: not-started
- 검증 여부: not-tested

## 목표

- 물고기가 2D 어항 안에서 자연스럽게 자동 이동한다.
- 물고기는 어항 경계 밖으로 나가지 않고, 이동 방향에 따라 이미지가 좌우 반전된다.

## 범위

- 포함할 것:
  - 좌우 이동 중심의 자동 이동
  - 약간의 상하 움직임
  - 경계 충돌 시 방향 반전
  - 이동 방향에 따른 이미지 좌우 반전
  - 랜덤한 속도와 방향 변화
- 제외할 것:
  - 복잡한 군집 이동
  - 물고기끼리 충돌 처리
  - 물고기 성장에 따른 움직임 변화

## 사용자 흐름

1. 사용자가 어항 화면을 본다.
2. 등록된 물고기가 자동으로 움직인다.
3. 물고기가 어항 경계에 닿으면 방향을 바꾼다.
4. 물고기 이동 방향이 바뀌면 이미지 방향도 함께 반전된다.

## UI/상태 요구사항

- 필요한 화면 요소:
  - 어항 영역
  - 움직이는 물고기 오브젝트
- 필요한 상태:
  - `swimming`: 자동 이동 중
  - `turning`: 방향 전환 중
- 오류 또는 빈 상태:
  - 물고기가 없으면 이동 루프가 오류 없이 유지된다.
  - 브라우저 탭 전환 후에도 물고기 위치가 비정상적으로 튀지 않는다.

## 이동 요구사항

- 기본 이동 로직은 다음 흐름을 따른다.

```text
현재 위치 + 방향 벡터 x 속도
-> 경계 충돌 시 방향 반전
-> 일정 시간마다 목표 위치 변경
-> 부드러운 보간 이동
```

- `requestAnimationFrame`을 사용한다.
- Canvas API 또는 PixiJS를 사용할 수 있다.
- 간단한 boids-like 이동은 추후 확장으로 남긴다.

## 추가 요구사항: 물고기 머리 방향 편집

- 물고기 목록의 `편집` 패널에서 등록 이미지의 원본 머리 방향을 수정할 수 있어야 한다.
- 방향 값은 `headDirection`으로 저장하며, 허용 값은 `right`와 `left`이다.
- 기존 저장 데이터에 `headDirection`이 없으면 `right`로 처리한다.
- 자동 이동 중 이미지 좌우 반전은 이동 방향(`vx`)과 `headDirection`을 비교해 계산한다.
- 기존 수동 `flipped` 값은 이미지 보정용으로 유지하고, 이동 방향 반전 결과와 합성한다.
- 검증 기준:
  - [ ] `편집` 패널에서 머리 방향을 `오른쪽` 또는 `왼쪽`으로 수정할 수 있다.
  - [ ] `headDirection`이 `left`인 물고기도 꼬리가 아니라 머리 방향으로 이동한다.
  - [ ] 방향 수정 후 저장 상태와 화면 반영이 즉시 갱신된다.

## 추가 요구사항: 물고기 이동 On/Off

- Add Fish Image 패널에서 등록할 물고기의 자동 이동 여부를 On/Off로 선택할 수 있어야 한다.
- 물고기 목록의 `편집` 패널에서 등록된 물고기의 자동 이동 여부를 On/Off로 수정할 수 있어야 한다.
- 이동 여부는 `movementEnabled`로 저장하며, 기존 저장 데이터에 값이 없으면 `true`로 처리한다.
- `movementEnabled`가 `false`인 물고기는 자동 이동 루프에서 위치, 방향, 상태가 갱신되지 않아야 한다.
- 검증 기준:
  - [ ] Add Fish Image에서 이동 Off로 등록한 물고기는 자동 이동하지 않는다.
  - [ ] `편집` 패널에서 이동 On/Off를 바꾸면 저장 상태와 화면 반영이 즉시 갱신된다.
  - [ ] 이동 Off인 물고기가 있어도 이동 루프와 빌드는 오류 없이 동작한다.
