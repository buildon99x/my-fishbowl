# S-005 물고기 움직임

## 상태

- 상태: ready
- 구현 여부: not-started
- 검증 여부: not-tested

## 목표

- 물고기가 2D 어항 안에서 자연스럽게 자동 이동한다.
- 물고기는 어항 경계 밖으로 나가지 않고, 이동 방향에 따라 이미지가 좌우 반전된다.

## 범위

- 포함할 것:
  - 좌우 이동 중심의 자동 이동
  - 약간의 상하 움직임
  - 경계 충돌 시 방향 반전
  - 이동 방향에 따른 이미지 좌우 반전
  - 랜덤한 속도와 방향 변화
- 제외할 것:
  - 복잡한 군집 이동
  - 물고기끼리 충돌 처리
  - 물고기 성장에 따른 움직임 변화

## 사용자 흐름

1. 사용자가 어항 화면을 본다.
2. 등록된 물고기가 자동으로 움직인다.
3. 물고기가 어항 경계에 닿으면 방향을 바꾼다.
4. 물고기 이동 방향이 바뀌면 이미지 방향도 함께 반전된다.

## UI/상태 요구사항

- 필요한 화면 요소:
  - 어항 영역
  - 움직이는 물고기 오브젝트
- 필요한 상태:
  - `swimming`: 자동 이동 중
  - `turning`: 방향 전환 중
- 오류 또는 빈 상태:
  - 물고기가 없으면 이동 루프가 오류 없이 유지된다.
  - 브라우저 탭 전환 후에도 물고기 위치가 비정상적으로 튀지 않는다.

## 이동 요구사항

- 기본 이동 로직은 다음 흐름을 따른다.

```text
현재 위치 + 방향 벡터 x 속도
-> 경계 충돌 시 방향 반전
-> 일정 시간마다 목표 위치 변경
-> 부드러운 보간 이동
```

- `requestAnimationFrame`을 사용한다.
- Canvas API 또는 PixiJS를 사용할 수 있다.
- 간단한 boids-like 이동은 추후 확장으로 남긴다.

## 구현 메모

- 관련 파일:
  - `src/main.js`
  - `src/styles/layout.css`
- 애니메이션 로직이 커지면 `src/features/fish-movement/`로 분리한다.
- 이동 계산과 DOM 또는 Canvas 렌더링은 함수 단위로 분리한다.

- [ ] 물고기에 약간의 상하 움직임이 적용된다.
- [ ] 물고기가 어항 경계 밖으로 나가지 않는다.
- [ ] 경계에 닿으면 이동 방향이 반전된다.
- [ ] 이동 방향에 따라 이미지가 좌우 반전된다.
- [ ] 속도 또는 방향이 일정 시간마다 자연스럽게 변한다.
- [ ] 브라우저 콘솔 오류가 없다.
- [ ] `npm run build`가 통과한다.
