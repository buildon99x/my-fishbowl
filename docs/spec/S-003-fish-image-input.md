# S-003 이미지 업로드 및 직접 그리기

## 상태

- 상태: ready
- 구현 여부: not-started
- 검증 여부: not-tested

## 목표

- 사용자가 이미지 파일을 업로드하거나 캔버스에 직접 그림을 그려 물고기 이미지를 만들 수 있다.
- 입력된 이미지는 물고기 오브젝트 생성에 사용할 2D 스프라이트 형태로 준비된다.

## 범위

- 포함할 것:
  - 사진 또는 이미지 파일 업로드
  - 직접 그리기 캔버스
  - PNG, JPG, JPEG, WEBP 파일 지원
  - 이미지 크기 자동 리사이즈
  - 물고기 이름 입력
  - 투명 배경 PNG 유지
- 제외할 것:
  - 필수 AI 배경 제거
  - 서버 업로드
  - 복잡한 이미지 편집 도구

## 사용자 흐름

1. 사용자가 물고기 추가 화면 또는 패널을 연다.
2. 사용자가 이미지 파일을 선택하거나 캔버스에 그림을 그린다.
3. 사용자가 물고기 이름을 입력한다.
4. 앱은 입력 이미지를 미리보기로 표시하고 2D 스프라이트로 사용할 데이터를 준비한다.

## UI/상태 요구사항

- 필요한 화면 요소:
  - 이미지 업로드 입력
  - 직접 그리기 캔버스
  - 미리보기 영역
  - 물고기 이름 입력
  - 등록 버튼
- 필요한 상태:
  - `idle`: 입력 전 상태
  - `preview`: 이미지 또는 그림 미리보기 가능 상태
  - `invalid`: 지원하지 않는 파일이거나 이미지 처리가 실패한 상태
- 오류 또는 빈 상태:
  - 지원하지 않는 파일 형식이면 사용자에게 등록 불가 상태를 표시한다.
  - 이미지가 없으면 등록 버튼은 비활성화하거나 등록을 막는다.

## 처리 요구사항

- 업로드한 이미지를 2D 스프라이트로 변환한다.
- MVP에서 배경 제거는 선택 기능으로 취급한다.
- 업로드 이미지를 원형 또는 물고기형 프레임 안에 넣을 수 있다.
- 좌우 반전 애니메이션으로 헤엄치는 느낌을 제공할 수 있게 이미지를 준비한다.

## 구현 메모

- 관련 파일:
  - `src/main.js`
  - `src/styles/components.css`
- 이미지 입력과 캔버스 편집 로직이 커지면 `src/features/fish-input/`로 분리한다.
- 브라우저 Canvas 리사이즈를 사용해 MVP 이미지 처리를 수행한다.

## 검증 기준

- [ ] PNG 파일을 선택하면 미리보기가 표시된다.
- [ ] JPG 또는 JPEG 파일을 선택하면 미리보기가 표시된다.
- [ ] WEBP 파일을 선택하면 미리보기가 표시된다.
- [ ] 직접 그린 그림을 물고기 이미지 입력으로 사용할 수 있다.
- [ ] 물고기 이름을 입력할 수 있다.
- [ ] 지원하지 않는 파일 형식은 등록되지 않는다.
- [ ] 브라우저 콘솔 오류가 없다.
- [ ] `npm run build`가 통과한다.
