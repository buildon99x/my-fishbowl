## 목표

  - 레이어 시스템

- 시각 영역 32px, hit area 56×56px.
- 선택 시 굵은 테두리 + scale 1.1.

### 2. 그리기 도구 (6종)

| 도구 | 아이콘 | 동작 |
|---|---|---|
| 펜 | ✏️ | 자유선 (얇음) |
| 굵은 붓 | 🖌️ | 자유선 (굵음) |
| 채우기 버킷 | 🪣 | 닫힌 영역 flood fill |
| 도형 스탬프 | ⭐ | 원/타원/삼각/별/심장/물방울 스탬프 |
| 지우개 | 🧽 | raster erase |
| 모두 지우기 | 🗑️ | 전체 클리어 (확인 모달 필요) |

각 버튼 56×56px.

### 3. 두께 단계

- 얇음 4px / 보통 10px (기본) / 굵음 22px

### 4. 자동 대칭 모드 (toggle)

- 좌우 대칭 미러 on/off.
- 활성 시 캔버스에 흐릿한 수직 가이드 라인 (opacity 0.1).
- 한쪽을 그리면 반대편에 미러 적용.
- **물고기 그리기에 압도적으로 유용**.

### 5. 되돌리기/다시하기

- 스택 깊이 30단계.
- Undo (↶) / Redo (↷) 56×56px 버튼.

### 6. 도형 스탬프

- 사전 정의 6종: 원, 타원, 삼각, 별, 심장, 물방울.
- 캔버스 탭 → 현재 색/크기로 스탬프.
- 드래그 → 크기 조절 후 confirm.

### 7. 자동 배경 제거 (사진 업로드)

- 라이브러리: `@imgly/background-removal` (ONNX Web, 클라이언트 사이드).
- 처리 중 spinner + "잠시만 기다려요" 이모지.
- 5초 초과 시 fallback: 원본 사용 옵션 + 수동 자르기.
- 결과 불만족 시 "원본 사용" 토글로 즉시 복귀.
- 저사양 디바이스 (`navigator.deviceMemory < 2`) 시 자동 비활성.

## 사용자 흐름 변경

1. "+" 클릭 → 그리기 모달 열림.
2. (옵션) "📷 사진" → 파일 선택 → 자동 배경 제거 → 캔버스에 표시.
3. 도구/색/두께 선택 후 그리기.
4. 등록 클릭 → S-004 + S-021 마법 모먼트.

## 안전·접근성

- 색맹 친화: 각 색에 이모지 라벨 (색만으로 구분 X).
- "모두 지우기"는 확인 모달.
- 캔버스 외부 터치 무시.
- 손가락/펜/마우스 동일 처리 (Pointer Events).
- 줌·팬 제스처는 캔버스 안에서 비활성.
- flood fill 큰 영역 stack overflow 방지: queue + iteration cap (1M 픽셀 이하).
- 부모 영역 옵션: "사진 업로드 사용 안 함" (배경 제거 5MB 번들 회피).
