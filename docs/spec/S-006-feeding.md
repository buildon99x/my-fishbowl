# S-006 먹이 주기

## 상태

- 상태: ready
- 구현 여부: not-started
- 검증 여부: not-tested

## 목표

- 사용자가 어항에 먹이를 뿌릴 수 있다.
- 근처 물고기는 먹이 방향으로 이동하고, 먹이를 먹으면 배고픔 수치가 감소한다.

## 범위

- 포함할 것:
  - 먹이 버튼
  - MVP 기본 먹이 1종
  - 어항 클릭 또는 드래그로 먹이 뿌리기
  - 먹이 입자 낙하
  - 근처 물고기의 먹이 반응
  - 간단한 먹는 애니메이션
- 제외할 것:
  - 여러 먹이 종류의 실제 효과 차이
  - 상점 기반 먹이 구매
  - 복잡한 포만감 또는 성장 시스템

## 사용자 흐름

1. 사용자가 먹이 버튼을 누른다.
2. 앱은 먹이 주기 모드로 전환한다.
3. 사용자가 어항을 클릭하거나 드래그한다.
4. 클릭한 위치에 먹이 입자가 생성되어 아래로 떨어진다.
5. 근처 물고기가 먹이 방향으로 이동한다.
6. 물고기가 먹이를 먹으면 배고픔 수치가 감소한다.

## UI/상태 요구사항

- 필요한 화면 요소:
  - 먹이 버튼
  - 먹이 종류 선택 UI
  - 먹이 입자
  - 먹는 애니메이션 또는 반응 표시
- 필요한 상태:
  - `feedingMode`: 먹이 주기 모드
  - `foodFalling`: 먹이 입자 낙하 중
  - `fishEating`: 물고기 먹이 반응 중
- 오류 또는 빈 상태:
  - 물고기가 없어도 먹이는 생성되고 낙하한다.
  - 어항 영역 밖 클릭은 먹이 생성으로 처리하지 않는다.

## 데이터 요구사항

| 항목 | 설명 |
| --- | --- |
| foodId | 먹이 ID |
| type | 먹이 종류 |
| x, y | 위치 |
| fallSpeed | 낙하 속도 |
| createdAt | 생성 시간 |

```ts
type Food = {
  id: string;
  type: "basic";
  x: number;
  y: number;
  fallSpeed: number;
  createdAt: string;
};
```

## 구현 메모

- 관련 파일:
