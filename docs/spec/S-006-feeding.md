# S-006 먹이 주기

## 상태

- 상태: ready
- 구현 여부: not-started
- 검증 여부: not-tested

## 목표

- 사용자가 어항에 먹이를 뿌릴 수 있다.
- 근처 물고기는 먹이 방향으로 이동하고, 먹이를 먹으면 배고픔 수치가 감소한다.

## 범위

- 포함할 것:
  - 먹이 버튼
  - MVP 기본 먹이 1종
  - 어항 클릭 또는 드래그로 먹이 뿌리기
  - 먹이 입자 낙하
  - 근처 물고기의 먹이 반응
  - 간단한 먹는 애니메이션
- 제외할 것:
  - 여러 먹이 종류의 실제 효과 차이
  - 먹이 종류 선택 UI (MVP는 1종만 사용)
  - 상점 기반 먹이 구매
  - 복잡한 포만감 또는 성장 시스템

## 사용자 흐름

1. 사용자가 먹이 버튼을 누른다.
2. 앱은 먹이 주기 모드로 전환한다.
3. 사용자가 어항을 클릭하거나 드래그한다.
4. 클릭한 위치에 먹이 입자가 생성되어 아래로 떨어진다.
5. 근처 물고기가 먹이 방향으로 이동한다.
6. 물고기가 먹이를 먹으면 배고픔 수치가 감소한다.
7. 사용자가 먹이 버튼을 다시 누르거나 5초간 추가 입력이 없으면 먹이 주기 모드가 종료된다.

## UI/상태 요구사항

- 필요한 화면 요소:
  - 먹이 버튼 (재클릭 시 모드 종료)
  - 먹이 입자
  - 먹는 애니메이션 또는 반응 표시
  - 먹이 주기 모드 진입 시 시각 피드백 (커서 변경 또는 어항 테두리 강조)
- 필요한 상태:
  - `feedingMode`: 먹이 주기 모드
  - `foodFalling`: 먹이 입자 낙하 중
  - `fishEating`: 물고기 먹이 반응 중
- 오류 또는 빈 상태:
  - 물고기가 없어도 먹이는 생성되고 낙하한다.
  - 어항 영역 밖 클릭은 먹이 생성으로 처리하지 않는다.
  - 먹이가 어항 바닥에 닿으면 5초 후 자동으로 사라진다 (메모리 누적 방지).

## 동작 파라미터

- 먹이 감지 반경: 150px (물고기 위치 기준, 이 안에 들어온 먹이를 추적)
- 먹이 섭취 거리: 12px (물고기와 먹이 사이 거리가 이 값 이하면 섭취 처리)
- 먹이 낙하 속도: 30~50px/s
- 배고픔 감소량: 먹이 1개당 -10 (배고픔 수치 정의는 추후 별도 스펙에서 확정, MVP는 임시값)
- 모드 자동 종료 시간: 마지막 입력 후 5초

## 데이터 요구사항

| 항목 | 설명 |
| --- | --- |
| id | 먹이 ID |
| type | 먹이 종류 (MVP는 `"basic"`만) |
| x, y | 위치 |
| fallSpeed | 낙하 속도 |
| createdAt | 생성 시간 (Unix timestamp ms, `Date.now()`) |
| landedAt | 바닥 도달 시간 (ms, 도달 전에는 `null`) |

```ts
type Food = {
  id: string;
  type: "basic";
  x: number;
  y: number;
  fallSpeed: number;
  createdAt: number;
  landedAt: number | null;
};
```

## 구현 메모

- 관련 파일 (초기부터 분리 권장):
  - `src/features/feeding/foodState.js` — 먹이 데이터 관리 및 라이프사이클
  - `src/features/feeding/foodPhysics.js` — 낙하 및 섭취 판정
  - `src/features/feeding/feedingMode.js` — 모드 진입/종료 및 입력 처리
  - `src/styles/components.css` — 먹이 버튼/커서 스타일
- 배고픔 수치 정의는 별도 스펙(추후 확정)에서 다루며, 본 스펙에서는 임시 감소량(-10)만 사용한다.
- MVP에서는 기본 먹이 1종만 구현한다.
