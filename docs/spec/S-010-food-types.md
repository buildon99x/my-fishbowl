# S-010 먹이 종류

## 상태

- 상태: draft
- 구현 여부: not-started
- 검증 여부: not-tested

## 의존성

- S-006 (먹이 주기)가 먼저 구현되어 있어야 한다.
- S-006의 `Food` 타입과 먹이 낙하/섭취 로직을 확장하는 형태로 동작한다.

## 목표

- 먹이를 3종으로 확장하고, 각 종류마다 시각·물리·효과 차이를 부여한다.
- 사용자가 아이콘 팔레트로 먹이 종류를 선택하고 어항에 뿌릴 수 있다.

## 범위

- 포함할 것:
  - 먹이 3종 정의 (플레이크, 펠릿, 장구벌레)
  - 종류별 시각 에셋 (미리 제작된 이미지 에셋 조합)
  - 종류별 낙하 물리 차이 (속도, 낙하 패턴)
  - 종류별 게임 효과 차이 (배고픔 감소량, 물고기 반응)
  - 먹이 종류 선택 아이콘 팔레트 UI
- 제외할 것:
  - 먹이 상점/구매 시스템
  - 먹이별 영양 성분, 성장 연동
  - 먹이 재고/수량 관리

## 먹이 종류 정의

### 설계 의도

세 종류는 단순한 시각 차이가 아니라 **사용 상황이 다르게 느껴지도록** 효과를 분담한다.

| 먹이 | 역할 | 사용자가 꺼내는 상황 |
|------|------|----------------------|
| 플레이크 | 분산형 — 1회 뿌리기로 다수 조각이 흩어짐 | 물고기가 많을 때, 모두에게 골고루 먹이고 싶을 때 |
| 펠릿 | 표준형 — 비교 기준이 되는 기본 먹이 | 일상적인 급여, 무난한 선택 |
| 장구벌레 | 고효율형 — 큰 배고픔 감소 + 일시 행동 변화 | 특별한 날, 물고기를 활발하게 만들고 싶을 때 |

이 차이는 배고픔 감소량, 낙하 패턴, 1회 생성 개수, 특수 효과의 조합으로 표현된다.

### 1. 바삭바삭 플레이크 (`flake`)

| 항목 | 내용 |
|------|------|
| 색상 | 노란색 (`#F5C842`) |
| 형태 | 곡선과 직선이 섞인 불규칙 다각형, 납작한 작은 조각 |
| 에셋 | `assets/food/flake-1.png`, `flake-2.png`, `flake-3.png` (3가지 변형을 랜덤 조합) |
| 낙하 속도 | 20~35px/s (느림 — 물에 떠서 천천히 가라앉는 느낌) |
| 낙하 패턴 | 좌우로 약간 흔들리며 낙하 (`sin` 파 수평 오프셋 ±5px) |
| 뿌리기 특성 | 클릭 1회에 3~5조각이 약간 흩어져 생성됨 |
| 배고픔 감소량 | 조각당 -5 (적음, 대신 여러 조각으로 보완) |
| 특수 효과 | 조각이 퍼지므로 여러 마리가 동시에 먹을 수 있음 |
| 바닥 잔류 시간 | 5초 |

### 2. 오독오독 펠릿 (`pellet`)

| 항목 | 내용 |
|------|------|
| 색상 | 주황색 (`#F07820`) |
| 형태 | 동그란 작은 알갱이 |
| 에셋 | `assets/food/pellet.png` (단일 에셋, 크기만 약간 랜덤) |
| 낙하 속도 | 50~70px/s (빠름 — 묵직하게 가라앉는 느낌) |
| 낙하 패턴 | 수직 낙하 (흔들림 없음) |
| 뿌리기 특성 | 클릭 1회에 1~2알 생성 |
| 배고픔 감소량 | 알갱이당 -15 (표준) |
| 특수 효과 | 없음 (가장 기본형) |
| 바닥 잔류 시간 | 8초 (무거워서 오래 남는 느낌) |

### 3. 톡특한 식감 냉동 장구벌레 (`bloodworm`)

| 항목 | 내용 |
|------|------|
| 색상 | 붉은색 (`#C0392B`) |
| 형태 | 길쭉한 작은 알갱이 |
| 에셋 | `assets/food/bloodworm.png` (수직/수평 2방향 에셋, 낙하 중 천천히 회전) |
| 낙하 속도 | 35~50px/s (중간) |
| 낙하 패턴 | 낙하 중 에셋이 천천히 회전 (0~360° 랜덤 속도) |
| 뿌리기 특성 | 클릭 1회에 1마리 생성 |
| 배고픔 감소량 | 마리당 -25 (많음) |
| 특수 효과 | ① 물고기 먹이 감지 반경 일시 확대 (150px → 220px, 10초간) <br>② 먹은 물고기의 `dart` 상태 발생 확률 일시 증가 (10% → 25%, 15초간) |
| 바닥 잔류 시간 | 5초 |

## 아이콘 팔레트 UI

- 먹이 버튼을 누르면 먹이 주기 모드로 진입하면서 아이콘 팔레트가 표시된다.
- 팔레트는 어항 하단 또는 먹이 버튼 주변에 가로 배열로 표시된다.
- 각 아이콘은 해당 먹이 에셋 이미지를 사용하며, 선택된 항목에 강조 테두리가 표시된다.
- 기본 선택은 `pellet` (중간 난이도의 표준 먹이).
- 팔레트에서 다른 먹이를 선택해도 먹이 주기 모드는 유지된다.

```
[ 🟡 플레이크 ]  [ 🟠 펠릿 ✓ ]  [ 🔴 장구벌레 ]
```

### 팔레트 상태

| 상태 | 표현 |
|------|------|
| 선택됨 | 테두리 강조 + 배경 밝아짐 |
| 미선택 | 기본 상태 |
| 호버 | 먹이 이름 툴팁 표시 |

## 데이터 요구사항

S-006의 `Food` 타입을 확장한다.

```ts
type FoodType = "flake" | "pellet" | "bloodworm";

type Food = {
  id: string;
  type: FoodType;
  x: number;
  y: number;
  fallSpeed: number;
  rotation: number;         // bloodworm 회전 각도 (deg)
  createdAt: number;
  landedAt: number | null;
};

type FoodTypeConfig = {
  type: FoodType;
  label: string;
  color: string;
  assets: string[];
  fallSpeedRange: [number, number];
  hungerReduction: number;
  countPerClick: [number, number];  // [min, max]
  landedTtl: number;               // 바닥 잔류 시간 (ms)
};
```

## 구현 메모

- 관련 파일:
  - `src/features/feeding/foodConfig.js` — 먹이 종류별 설정(`FoodTypeConfig`) 관리 (신규)
  - `src/features/feeding/foodState.js` — S-006 `Food` 타입에 `rotation`, `type` 확장
  - `src/features/feeding/foodPhysics.js` — 종류별 낙하 패턴 분기 추가
  - `src/features/feeding/feedingMode.js` — 팔레트 선택 상태 관리 추가
  - `src/features/feeding/foodEffects.js` — 섭취 후 물고기 효과 적용 (신규)
  - `src/styles/components.css` — 팔레트 UI 스타일
  - `assets/food/` — 에셋 디렉터리 (신규)
- 에셋은 PNG 또는 SVG로 제작, 24×24px 기준.
- `flake`의 흩어짐은 생성 시 x 좌표에 ±20px 이내 오프셋을 적용하여 구현.
- `bloodworm`의 특수 효과는 S-009의 `fishBehavior.js` 상태 머신에 외부 modifier를 주입하는 방식으로 처리.
