# S-002 어항 생성

## 상태

- 상태: ready
- 구현 여부: done
- 검증 여부: tested

## 목표

- 사용자가 처음 접속하면 기본 2D 어항이 생성된다.
- 물고기가 움직일 수 있는 어항 영역과 사용자별 어항 데이터를 준비한다.

## 범위

- 포함할 것:
  - 기본 어항 배경 제공
  - 둥근 유리 수조 형태의 2D 어항 영역 렌더링
  - 물고기가 움직일 수 있는 경계 영역 정의
  - 물 색상, 유리 외곽선, 기포, 기본 장식 요소 표시
  - 로컬 저장소 기반 사용자별 어항 데이터 저장
- 제외할 것:
  - 로그인
  - 서버 저장
  - 친구 어항 방문

## 사용자 흐름

1. 사용자가 앱에 처음 접속한다.
2. 앱은 로컬 저장소에 기존 어항 데이터가 있는지 확인한다.
3. 기존 데이터가 없으면 기본 어항 데이터를 생성한다.
4. 생성된 어항 배경과 수조 영역이 화면에 표시된다.

## UI/상태 요구사항

- 필요한 화면 요소:
  - 둥근 수조 형태의 어항 영역
  - 연한 파란색 물 배경
  - 유리 수조 외곽선
  - 물고기가 움직일 수 있는 내부 수영 영역
  - 기포 또는 수초 같은 기본 장식 요소
  - 어항 이름 또는 제목
  - 청결도와 물고기 수를 표시할 상태 영역
- 필요한 상태:
  - `empty`: 물고기가 없는 기본 어항
  - `ready`: 어항 데이터가 생성되어 표시 가능한 상태
- 오류 또는 빈 상태:
  - 로컬 저장소를 사용할 수 없어도 기본 어항은 화면에 표시된다.
  - 물고기가 없는 상태에서도 어항 영역은 비어 있는 수조로 표시된다.

## 디자인 기준

- 참고 이미지: `docs/draft/init-design/KakaoTalk_20260506_103304667_01.jpg`
- 어항은 사각형 박스가 아니라 세로로 긴 둥근 수조 실루엣으로 표현한다.
- 수조 외곽은 손그림 느낌의 굵은 선 또는 부드러운 곡선 테두리로 표시한다.
- 내부 물은 연한 파란색 계열로 채우되, 물고기와 장식이 잘 보이도록 낮은 채도와 낮은 불투명도를 유지한다.
- 물고기 이동 경계는 외곽선 안쪽으로 여백을 둔 내부 영역으로 정의한다.
- 수조 밖으로 물고기, 먹이, 이끼, 장식이 벗어나 보이지 않도록 어항 마스크 또는 클리핑 영역을 둔다.
- 기본 장식은 물고기 생성과 별개로 어항 생성 시 표시할 수 있다.
  - 상단 또는 측면 기포
  - 좌측 상단 수초
  - 좌측 하단 작은 소품 또는 장식
- 장식 요소는 물고기 이동을 막는 장애물이 아니라 배경 장식으로 취급한다.

## 경계 요구사항

- 어항의 시각적 외곽선과 실제 이동 가능 영역을 구분한다.
- 실제 이동 가능 영역은 외곽선보다 안쪽에 위치해야 한다.
- 둥근 어항 형태를 따르기 어렵다면 MVP에서는 타원형 또는 캡슐형 경계로 근사할 수 있다.
- 경계 정보는 물고기 움직임, 먹이 낙하, 이끼 레이어, 청소 입력에서 재사용할 수 있어야 한다.

## 데이터 요구사항

```ts
type Aquarium = {
  id: string;
  userId?: string;
  name: string;
  fishes: Fish[];

    width: number;

  };

```

## 구현 메모

- 관련 파일:
  - `src/main.js`
  - `src/styles/layout.css`
  - `src/styles/components.css`
- `ARCHITECTURE.md` 기준으로 초기 구현은 `src/main.js`에 둘 수 있다.
- 어항 생성과 저장 로직이 커지면 `src/features/aquarium/`로 분리한다.
- MVP는 로그인 없이 로컬 저장소 기반으로 시작하고, 추후 계정 기반 저장으로 확장 가능해야 한다.
