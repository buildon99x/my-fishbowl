# S-011 어항 거품 효과

## 상태

- 상태: done
- 구현 여부: done
- 검증 여부: not-tested

## 목표

- 어항 바닥의 모래, 해초, 정원 장어 주변에서 거품이 가끔 자연스럽게 발생하여 수면을 향해 올라간다.
- 거품은 랜덤한 시점에 일시정지되었다가 다시 발생을 재개하여 실제 수조처럼 생동감 있게 연출한다.

## 범위

- 포함할 것:
  - 5개 소스(모래, 해초 좌·우, 정원 장어 1·2) 각각에서 독립적인 간격으로 거품 발생
  - 거품의 상승, 좌우 흔들림(정현파 drift), 페이드 인/아웃
  - 전체 발생을 2~5초 일시 중단하는 랜덤 포즈 메커니즘
  - 포즈 해제 후 거품이 한꺼번에 터지는 버스트 방지 (소스 타이머 분산)
  - 기존 레이어 순서 유지 (거품은 물고기·이끼 뒤에 표시)
- 제외할 것:
  - 물고기 움직임과 연동되는 거품 (물고기가 이동할 때 추가 거품 발생 등)
  - 사용자가 거품 빈도나 크기를 직접 조정하는 설정 UI
  - 거품이 수면에 닿는 파문 효과

## 사용자 흐름

1. 사용자가 어항 화면을 연다.
2. 페이지 로드 후 약 10~36초 경과 시 처음으로 거품이 등장하기 시작한다.
3. 거품은 모래, 해초, 장어 발생 위치에서 하나씩 솟아오르며 수면 근처에서 서서히 사라진다.
4. 가끔 전체 거품 발생이 2~5초 동안 멈췄다가 자연스럽게 재개된다.
5. 이미 상승 중인 거품은 포즈 중에도 계속 올라간다.

## UI/상태 요구사항

- 필요한 화면 요소:
  - 거품 레이어 SVG (`.bubble-layer`) — 어항 장식 SVG 위, 이끼 레이어 아래에 겹침
  - 거품 파티클 (`<g>` 엘리먼트) — 거품 원과 하이라이트 점으로 구성
- 필요한 상태 (런타임 전용, 저장 불필요):
  - `bubbles[]` — 현재 상승 중인 거품 목록
  - `sources[]` — 발생 소스별 다음 발생 예정 시각(`nextEmitAt`)
  - `pauseUntilMs` — 현재 포즈 종료 시각 (0 = 포즈 없음)
  - `nextPauseAt` — 다음 포즈 시작 예정 시각
- 오류 또는 빈 상태:
  - 거품 레이어 SVG를 찾지 못하면 무음 처리 (애니메이션 없이 앱 정상 동작)
  - 앱 재렌더 시 기존 거품 상태는 보존되고 DOM만 재구성된다.

## 거품 발생 소스

SVG viewBox 좌표계(`0 0 1152 780`) 기준이다.  
모든 소스는 모래 표면(y ≈ 648–651)에서 발생한다. 정원 장어 소스를 장어 머리 위치(y ≈ 430)가 아닌 모래 바닥(y ≈ 648)으로 설정한 이유는, 장어 머리가 `eel-sway` CSS 애니메이션으로 ±15 SVG units 흔들리므로 정적 좌표를 사용하면 거품이 허공에서 발생하는 것처럼 보이기 때문이다.

| ID | 위치 설명 | x 범위 | y | 발생 간격 |
| --- | --- | --- | --- | --- |
| `sand` | 모래 바닥 (랜덤 위치) | 320–840 | 651 | 12–28초 |
| `seaweed-left` | 왼쪽 해초 뿌리 | 302–342 | 648 | 14–32초 |
| `seaweed-right` | 오른쪽 해초 뿌리 | 814–844 | 651 | 16–36초 |
| `eel-one` | 정원 장어 1 모래 뿌리 | 506–524 | 648 | 10–24초 |
| `eel-two` | 정원 장어 2 모래 뿌리 | 634–652 | 649 | 12–28초 |

## 거품 물리

| 속성 | 값 범위 | 설명 |
| --- | --- | --- |
| `radius` | 3–11 SVG units | 거품 크기 |
| `riseSpeed` | 35–60 SVG units/s | 상승 속도 — 빠를수록 이동 시간이 짧아져 동시 거품 수를 제한 |
| `driftAmplitude` | 4–13 SVG units | 좌우 흔들림 최대 폭 |
| `driftSpeed` | 0.6–1.6 rad/s | 흔들림 주기 속도 |

x 위치는 `originX + sin(driftPhase) × driftAmplitude`로 계산한다.  
수면(`WATER_TOP_Y = 158`) 도달 시 거품 제거.  
페이드 인: 발생 후 24 SVG units 이동까지, 페이드 아웃: 수면 55 SVG units 아래 구간.

## 포즈(일시정지) 메커니즘

- **첫 포즈**: 로드 후 20–40초 경과 시 (즉시 중단 방지)
- **포즈 지속시간**: 2–5초
- **포즈 간 간격**: 포즈 종료 후 15–35초 뒤 다음 포즈 예약
- **버스트 방지**: 포즈 시작 시, 포즈 기간 내에 만료 예정인 소스 타이머를 포즈 종료 후 0–4초 범위에 랜덤 재배치하여 재개 직후 동시 발생을 막는다.
- 포즈 중 이미 상승 중인 거품은 계속 이동한다.

## 레이어 순서

```
어항 장식 SVG (.aquarium-art)   — 배경, z-index 없음
  .bubble-layer SVG             — z-index: 2  ← 거품
  .algae-layer canvas           — z-index: 3
  .fish-layer div               — z-index: 4  (stacking context)
    food pellets                    z-index: 6 (fish-layer 내부)
    fish sprites                    z-index: 8 (fish-layer 내부)
```

거품이 물고기·이끼 뒤에 위치함으로써 물고기가 시각적으로 앞으로 돌출되어 보이고, 이끼가 짙어질수록 거품도 자연스럽게 가려진다.

## 구현 메모

- 관련 파일:
  - `src/features/bubbles/state.js` — 상태 관리, 물리 tick 함수, 포즈 로직
  - `src/features/bubbles/index.js` — `requestAnimationFrame` 루프, SVG DOM 직접 조작
  - `src/features/bubbles/state.test.js` — 단위 테스트
  - `src/styles/components.css` — `.bubble-layer` 스타일
  - `src/main.js` — `bubblesState` 생성, bubble-layer HTML 삽입, 컨트롤러 생명주기
- 거품 상태(`bubblesState`)는 `appState`에 보관하며 앱 재렌더 시 유지된다.
- 거품 애니메이션은 물고기 이동 루프(`movementController`)와 독립적인 별도 `requestAnimationFrame` 루프로 동작한다.
- DOM 조작은 `innerHTML` 재렌더 없이 `<g>` 엘리먼트 추가/제거/속성 갱신만 사용한다.
- 거품 상태는 `localStorage`에 저장하지 않는다 (런타임 전용).
