# S-001 Fishbowl MVP Initial Screen

## 상태

- 상태: ready
- 구현 여부: not-started
- 검증 여부: not-tested

## 목표

- 사용자에게 Fishbowl MVP의 목적이 드러나는 초기 화면을 제공한다.
- 사용자가 버튼 클릭 등 단일 핵심 상호작용을 수행하면 화면 상태가 즉시 변경된다.

## 범위

- 포함할 것:
  - `#app`에 초기 UI 렌더링
  - 제목/설명/핵심 버튼으로 구성된 기본 화면
  - 버튼 상호작용 후 상태 텍스트 또는 카드 내용 변경
- 제외할 것:
  - 로그인
  - 서버 API 호출
  - 다중 페이지 라우팅

## 사용자 흐름

1. 사용자가 앱을 열면 초기 Fishbowl 화면이 렌더링된다.
2. 사용자가 핵심 액션 버튼을 클릭한다.
3. 화면의 상태 텍스트(또는 카드 내용)가 변경되어 상호작용 결과를 즉시 보여준다.

## UI/상태 요구사항

- 필요한 화면 요소:
  - 화면 제목 1개
  - 설명 텍스트 1개
  - 액션 버튼 1개
  - 결과/상태 표시 영역 1개
- 필요한 상태:
  - `idle`(초기 상태)
  - `updated`(상호작용 이후 상태)
- 오류 또는 빈 상태:
  - 콘솔 오류 없이 동작
  - 초기 상태에서 결과 영역은 안내 문구를 표시

## 구현 메모

- 관련 파일:
  - `index.html`
  - `src/main.js`
  - `src/styles/base.css`
  - `src/styles/layout.css`
  - `src/styles/components.css`
- `ARCHITECTURE.md` 기준으로 현재는 `src/main.js` 단일 파일 구현을 유지하고, 기능이 커지면 `src/features/`로 분리한다.

## 검증 기준

- [ ] 초기 로드 시 제목/설명/버튼/상태 영역이 표시된다.
- [ ] 버튼 클릭 시 상태 표시 텍스트가 변경된다.
- [ ] 브라우저 콘솔 오류가 없다.
- [ ] `npm run build`가 통과한다.
