## 보강 1: 어린이 친화 성격 라벨

draft의 개체별 파라미터(`speedMultiplier`, `idleBias`, `preferredDepth`)는 내부 수치다. 어린이가 "내 물고기는 어떤 친구야?" 인지할 수 있게 **파생 라벨**을 자동 부여한다.

### 라벨 도출 규칙

평가 우선순위(위에서부터 첫 번째 매칭만 적용 — 중복 매칭 방지):

| 우선순위 | 라벨 | 조건 | 사용자 표시 |
|---|---|---|---|
| 1 | `lazy`  | idleBias > 0.2 | "느긋한 친구" 😌 |
| 2 | `swift` | speedMultiplier ≥ 1.25 AND idleBias ≤ 0.2 | "재빠른 친구" ⚡ |
| 3 | `lively` | speedMultiplier ≥ 1.15 AND idleBias ≤ 0.1 | "활발한 친구" 🎉 |
| 4 | `gentle` | 그 외 (기본값) | "온순한 친구" 🌱 |

라벨은 prop-panel 상단에 항상 표시되는 badge(이모지+텍스트). 어린이가 자신의 친구를 즉시 인지할 수 있어야 하므로 "선택적"이 아님.

## 보강 2: 터치 디바이스 회피 정책

draft는 "마우스 80px 이내 dart"만 정의 — 터치 환경에 마우스가 없다.

- 터치 환경: `pointerdown` + `pointermove`가 진행 중일 때만 회피 발동.
- 단순 탭(빠른 down/up)은 회피 트리거가 아님.
- 탭 시 회피 대신 **놀람 반응**: 0.3초 멈칫 → 부드러운 방향 전환.
- 어린이가 "와, 반응했다!" 정서를 얻음.

## 보강 3: 마법 모먼트 합류 타이밍

- S-021 Phase C 종료 시점에 행동 머신에 등록.
- 첫 3초간 강제로 `cruising` + `speedMultiplier × 0.7` (천천히 헤엄).
- 어린이가 새 친구를 충분히 관찰할 수 있는 grace period.

## 보강 4: 사운드 옵션 (기본 OFF)

- 행동 상태 전환 시 옅은 ambient 효과음(볼륨 0.15).
- 기본 OFF (10마리 환경 청각 과부하 방지).
- 부모 영역에서 켤 수 있음.

## 보강 5: prop-panel 노출

- 개체별 파라미터 수치는 어린이에게 직접 노출하지 않는다.
- prop-panel에 **성격 라벨 badge**(항상 표시, 선택적 아님)와 **"성격 다시 뽑기" 버튼**(🎲) 추가.
- "다시 뽑기"는 파라미터를 새 랜덤값으로 재할당.
- **연타 방지**: 동일 물고기에 대한 다시 뽑기는 5초 쿨다운 (버튼 비활성+남은 초 표시).
- 일일 한도는 두지 않는다 — 4–8세 사용자에게 "오늘은 못 해" 메시지는 좌절을 유발하므로, 쿨다운만으로 남용을 충분히 억제한다.

## 보강 6: 데이터 모델

기존 fish 데이터에 추가:

```ts
type FishPersonality = {
  speedMultiplier: number;
  idleBias: number;
  preferredDepth: 'top' | 'middle' | 'bottom';
  wavingFrequency: number;
  wavingAmplitude: number;
  label: 'lively' | 'gentle' | 'lazy' | 'swift';  // 도출값 (우선순위 규칙)
  lastRerollAt?: number;  // epoch ms — 5초 쿨다운 계산용
};
```

- 기존 저장 데이터는 마이그레이션 시 `normalizeAquarium`이 누락된 personality 필드를 랜덤 보정.
- 라벨은 마이그레이션 시 도출 규칙으로 계산해 저장.

## UX 리뷰 결정 사항

| 쟁점 | 원안 | 결정 | 근거 |
|---|---|---|---|
| reroll 한도 | 일일 5회 | 한도 없음 + 5초 쿨다운 | 4–8세에게 "오늘은 못 해" = 좌절. 쿨다운으로 연타만 막으면 충분 |
| 라벨 우선순위 | 미정의 (중복 매칭 가능) | `lazy → swift → lively → gentle` 첫 매칭만 | 한 물고기에 두 라벨이 깜빡이면 인지 혼란 |
| badge 표시 | 선택적 | 항상 표시 (이모지+텍스트) | "내 친구가 어떤 친구인지" = 마법 모먼트 직후 핵심 인지 |
| 사운드 옵션 | 기본 OFF | 유지 (기본 OFF) | 10마리 환경 청각 과부하 방지 (S-022 정책과 일치) |

### 충돌/연동 정리

- **S-021**: Phase C 종료 시점에 행동 머신 등록 — S-021 §사용자 흐름 5–7과 정합.
- **S-013**: prop-panel 상단에 badge 표시 영역 추가 필요 → S-013 patch 항목으로 추적.
- **S-022**: 사운드 옵션은 `interaction` 카테고리 하위 토글이 아닌 **별도 "성격 변화 효과음"** 옵션으로 부모 영역에 노출 (혼동 방지).
