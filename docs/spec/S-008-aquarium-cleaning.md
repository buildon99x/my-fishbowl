# S-008 어항 청소

## 상태

- 상태: ready
- 구현 여부: not-started
- 검증 여부: not-tested

## 목표

- 사용자가 청소 모드에서 화면을 문질러 이끼를 제거할 수 있다.
- 일정 비율 이상 이끼를 제거하면 청소가 완료되고 청결도가 회복된다.

## 범위

- 포함할 것:
  - 청소 모드 버튼
  - 마우스 또는 터치 드래그 입력
  - 원형 브러시 기반 이끼 제거
  - 청소 진행률 표시
  - 청소 완료 처리와 청결도 회복
  - 모바일 터치 지원
- 제외할 것:
  - 여러 청소 도구
  - 도구 구매 또는 업그레이드
  - 복잡한 물리 기반 닦기 효과

## 사용자 흐름

1. 사용자가 청소 버튼을 누른다.
2. 앱은 청소 모드로 전환하고 브러시 커서를 표시한다.
3. 사용자가 어항 화면을 마우스 또는 터치로 드래그한다.
4. 드래그한 영역의 이끼가 제거된다.
5. 일정 비율 이상 제거되면 청소 완료 메시지가 표시된다.
6. 청결도와 마지막 청소 시간이 갱신된다.

## UI/상태 요구사항

- 필요한 화면 요소:
  - 청소 모드 버튼
  - 청소 브러시 커서
  - 청소 진행률
  - 완료 메시지
- 필요한 상태:
  - `cleaningMode`: 청소 모드
  - `cleaning`: 드래그로 청소 중
  - `cleaned`: 청소 완료
- 오류 또는 빈 상태:
  - 이끼가 없는 상태에서 청소해도 오류 없이 완료 또는 비활성 상태를 표시한다.
  - 어항 영역 밖 드래그는 청소 처리하지 않는다.

## 처리 요구사항

- 드래그 위치를 따라 원형 브러시를 적용한다.
- 이끼 레이어의 투명도를 감소시킨다.
- 일정 비율 이상 제거되면 청소를 완료한다.
- 청소 완료 시 청결도를 회복하고 마지막 청소 시간을 갱신한다.

## 구현 메모

- 관련 파일:
  - `src/main.js`
  - `src/styles/components.css`
- Canvas 위에 이끼 레이어를 생성하고 `globalCompositeOperation = destination-out` 방식으로 지운다.
- 청소 입력과 진행률 계산이 커지면 `src/features/cleaning/`로 분리한다.
