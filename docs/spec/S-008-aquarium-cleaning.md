# S-008 어항 청소

## 상태

- 상태: ready
- 구현 여부: done
- 검증 여부: tested

## 목표

- 사용자가 청소 모드에서 마우스 또는 터치로 이끼를 문질러 제거할 수 있다.
- 실제로 보이는 이끼 픽셀의 80% 이상을 제거하면 청소가 완료된다.
- 청소 완료 시 이끼 상태와 청결도가 회복된다.

## 범위

- 포함:
  - 청소 모드 진입 버튼
  - 청소 취소 버튼
  - 마우스 드래그와 터치 드래그 입력
  - 원형 브러시 기반 Canvas 이끼 제거
  - 보이는 이끼 픽셀 기준 진행률 계산
  - 청소 완료 처리와 상태 저장
- 제외:
  - 여러 청소 도구
  - 청소 도구 구매 또는 업그레이드
  - 복잡한 물리 기반 닦기 효과

## 사용 흐름

1. 사용자가 이끼가 있는 상태에서 청소 버튼을 누른다.
2. 앱은 청소 모드로 전환하고 취소 버튼, 진행률, 브러시 커서를 표시한다.
3. 사용자가 어항 위를 드래그한다.
4. 브러시 영역의 이끼가 `destination-out` 방식으로 제거된다.
5. 앱은 남은 보이는 이끼 픽셀 수를 기준으로 진행률을 갱신한다.
6. 진행률이 80% 이상이면 청소 완료 상태가 된다.
7. 완료 즉시 남은 이끼 Canvas를 비우고 진행률을 100%로 표시한다.
8. 1.5초 뒤 청소 모드가 자동 종료된다.

## UI/상태 요구사항

- 필요한 화면 요소:
  - 청소 모드 버튼
  - 청소 취소 버튼
  - 청소 진행률 바
  - 청소 브러시 커서
  - 청소 완료 메시지
- 필요한 상태:
  - `cleaningMode`: 청소 모드 활성 여부
  - `cleaning`: 드래그 중 여부
  - `cleaned`: 청소 완료 여부
  - `cleaningProgress`: 0~1 진행률
  - `initialAlgaePixels`: 청소 시작 시 보이는 이끼 픽셀 수
  - `snapshotData`: 취소 복원용 Canvas 스냅샷
- 오류 또는 빈 상태:
  - 이끼가 없으면 청소 버튼은 비활성화된다.
  - 어항 영역 밖 드래그는 청소 처리하지 않는다.
  - 취소 시 청소 모드를 종료하고 진행 상태를 초기화한다.

## 완료 판정

- 완료 기준은 `cleaningProgress >= 0.8`이다.
- `cleaningProgress`는 알파값 합계가 아니라 보이는 이끼 픽셀 개수 기준으로 계산한다.
- 알파가 매우 낮은 가장자리 노이즈는 보이는 이끼 픽셀로 보지 않는다.
- 완료 시점에는 상태 저장과 별개로 Canvas를 즉시 비워서 완료 메시지와 남은 이끼가 동시에 보이지 않도록 한다.
