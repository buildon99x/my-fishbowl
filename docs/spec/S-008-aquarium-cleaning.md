# S-008 어항 청소

## 상태

- 상태: done
- 구현 여부: done
- 검증 여부: tested

## 목표

- 사용자가 청소 모드에서 마우스 또는 터치로 이끼를 문질러 제거할 수 있다.
- 실제로 보이는 이끼 픽셀의 80% 이상을 제거하면 청소가 완료된다.
- 청소 완료 시 이끼 상태와 청결도가 회복된다.

## 범위

- 포함:
  - 청소 모드 진입 버튼
  - 청소 취소 버튼
  - 마우스 드래그와 터치 드래그 입력
  - 원형 브러시 기반 Canvas 이끼 제거
  - 보이는 이끼 픽셀 기준 진행률 계산
  - 청소 완료 처리와 상태 저장
- 제외:
  - 여러 청소 도구
  - 청소 도구 구매 또는 업그레이드
  - 복잡한 물리 기반 닦기 효과

## 사용 흐름

1. 사용자가 청소 버튼을 누른다.
2. 앱은 청소 모드로 전환하고, 어항 테두리를 하이라이트하며 노란 스폰지 커서를 표시한다.
3. 사용자가 어항 화면을 마우스 또는 터치로 드래그한다.
4. 드래그한 영역의 이끼가 제거되고, 상단 진행률 바가 갱신된다.
5. 80% 이상 제거되면 청소 완료 메시지가 표시된다.
6. 1.5초 후 청소 모드가 자동으로 종료되고 일반 모드로 복귀한다.
7. 청결도와 마지막 청소 시간이 갱신된다.
8. (선택) 사용자가 완료 전에 취소 버튼 또는 ESC 키를 누르면 청소 모드가 종료되고 이끼 상태가 복원된다.

## UI/상태 요구사항

- 필요한 화면 요소:
  - 청소 모드 버튼
  - 청소 취소 버튼 (청소 모드 진입 시 표시)
  - 청소 브러시 커서 — **노란 스폰지 모양** CSS 커서 (이미지 없음, 순수 CSS로 구현)
  - 어항 테두리 하이라이트 (청소 모드에서 청소 가능 영역 강조)
  - 청소 진행률 바 (어항 상단 고정, 0~100%)
  - 완료 메시지 (1.5초 후 자동 닫힘)
- 필요한 상태:
  - `cleaningMode`: 청소 모드 활성 여부
  - `cleaning`: 드래그로 청소 중
  - `cleaned`: 청소 완료 (80% 이상 제거)
  - `cleaningProgress`: 현재 제거된 이끼 비율 (0.0~1.0)
  - `snapshotData`: 청소 시작 전 이끼 레이어 스냅샷 (취소 시 복원용)
  - `initialAlphaSum`: 청소 시작 시점의 전체 알파 합계
- 완료 임계값:
  - `COMPLETION_THRESHOLD = 0.8` — 이끼의 **80% 이상** 제거 시 청소 완료로 처리한다.
- 오류 또는 빈 상태:
  - 이끼가 없는 상태에서 청소 버튼이 비활성화된다.
  - 어항 영역 밖 드래그는 청소 처리하지 않는다.
  - 취소 시 청소 모드를 종료하고 진행 상태를 초기화한다.

## 완료 판정

- 드래그 위치를 따라 원형 브러시(`BRUSH_RADIUS = 40`)를 적용한다.
- `globalCompositeOperation = 'destination-out'`으로 이끼 레이어의 알파를 감소시킨다.
- 브러시는 라디얼 그라데이션 (중심 100% → 70% 85% → 외곽 0%)으로 부드럽게 지운다.
- **알파 합계(alpha-sum)** 방식으로 진행률을 실시간 계산한다:
  ```
  progress = 1 - sumAlpha(currentImageData) / initialAlphaSum
  ```
  - `SAMPLE_STEP = 4` — 4픽셀마다 샘플링 (성능 최적화)
  - 이진 카운트 방식은 반투명 가장자리 픽셀로 인해 조기 완료 버그가 발생하므로 채택하지 않는다.
- `cleaningProgress >= 0.8` 이면 청소를 완료 처리한다.
- 청소 완료 후 1.5초 뒤 자동으로 청소 모드를 종료한다.
- 청소 취소 시 스냅샷(`snapshotData`)으로 이끼 레이어를 복원한다.
- 청소 완료 시 청결도를 회복하고 마지막 청소 시간을 갱신한다.

## 청소 브러시 커서

청소 모드 진입 시 마우스 커서 대신 **노란 스폰지** 모양의 커서 요소(`.cleaning-cursor`)가 표시된다.

- 구현: `.cleaning-cursor` div를 `mousemove` 이벤트로 절대 위치 이동
- 모양: `border-radius`로 불규칙한 사각형, 방사형 그라데이션 점들로 기공 텍스처 표현
- 정렬: `transform: translate(-50%, -50%) rotate(-7deg)` — 커서 중심 기준 정렬
- 표시: 청소 모드 진입 시 `cursor.style.display = 'block'` (빈 문자열 사용 시 CSS `display: none`에 의해 숨겨지는 버그가 있어 명시적 `'block'` 사용)
- 숨김: 청소 모드 종료 시 `cursor.style.display = 'none'`
