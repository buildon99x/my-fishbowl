# S-021 어항 경계(타원) 충돌로 물고기 이탈 방지

## 상태

- 상태: ready
- 구현 여부: not-started
- 검증 여부: not-tested

## 목표

- 물고기가 어항(둥근 유리벽) 밖으로 벗어나는 버그(이슈 #16)를 해결한다.
- 1·2시 / 4·5시 / 7·8시 / 10·11시 방향(직사각형의 네 모서리)에서 물고기가 유리벽 바깥으로 빠져나가는 현상을 차단한다.

## 범위

- 포함할 것:
  - `fish-layer`(타원 형태)에 맞는 타원형 충돌 경계 도입
  - 직사각형 경계(`MOVEMENT_BOUNDS`) 외에 타원 경계를 함께 적용해 모서리 누수 차단
  - 타원 벽에 닿았을 때 기존의 벽 일시정지(wall pause)·재출발 흐름과 동일한 처리 적용
  - 단위 테스트로 모서리 위치에서 타원 안쪽으로 클램핑되는지 검증
- 제외할 것:
  - 시각 자산(`decoration.js`의 SVG 경로) 변경
  - `aquarium.css`의 `fish-layer` 위치/크기 변경
  - 새로운 충돌 모양(라운드 사각형 등) 도입

## 사용자 흐름

1. 사용자가 어항 화면을 보고 있을 때, 물고기는 자유롭게 헤엄친다.
2. 물고기가 1·2·4·5·7·8·10·11시 방향(어항 모서리)으로 향하더라도 타원 유리벽 안에 머문다.
3. 물고기가 벽에 닿으면 기존과 동일하게 잠시 멈췄다가 안쪽으로 방향을 바꿔 다시 헤엄친다.

## UI/상태 요구사항

- 필요한 화면 요소: 기존 `fish-layer` 그대로.
- 필요한 상태: `MOVEMENT_BOUNDS`에 타원 파라미터(`ellipse: { cx, cy, rx, ry }`)를 추가한다.
  - 권장값: `cx=50, cy=50, rx=46, ry=42` (현재 직사각형 경계 `4..96 / 8..92`에 내접하는 타원).
- 오류 또는 빈 상태: 해당 없음. 기존 동작 회귀가 없어야 한다.

## 구현 메모

- 관련 파일:
  - `src/features/fish-movement/state.js` — `MOVEMENT_BOUNDS`에 `ellipse` 추가, `stepFishMovement`에 타원 경계 충돌 처리 추가.
  - `src/features/fish-movement/state.test.js` — 모서리 좌표(예: `(96, 92)`)에서 물고기가 타원 안쪽으로 보정되고 `wallPauseUntilMs`가 설정되는지 검증.
- `ARCHITECTURE.md` 기준 새 파일/디렉터리 필요 여부: 없음. 기존 모듈 내부에서 처리한다.

### 알고리즘 메모

- 정규화 거리 `r = sqrt(((x-cx)/rx)^2 + ((y-cy)/ry)^2)` 가 1 이상이면 타원 밖으로 판단.
- 위치는 `x = cx + (x-cx)/r`, `y = cy + (y-cy)/r` 로 타원 위로 투영해 클램핑.
- 기존 직사각형 벽 처리와 동일하게 `vx = 0; vy = 0; behaviorStatus = 'idle'`로 멈추고
  `wallPauseUntilMs`를 설정한 뒤, 재출발 시 어항 안쪽 방향(중심을 향하는 단위벡터)으로 `wallResumeVx/Vy`를 설정.

- [ ] 브라우저에서 어항을 관찰할 때 1·2·4·5·7·8·10·11시 방향으로 물고기가 빠져나가지 않는다.
- [ ] `npm test`, `npm run lint`, `npm run build`가 통과한다.
