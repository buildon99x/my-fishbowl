# S-009 물고기 생동감 향상

## 상태

- 상태: draft
- 구현 여부: not-started
- 검증 여부: not-tested

## 목표

- S-005의 기본 이동 위에 "살아있는 듯한" 인상을 주는 행동/시각적 디테일을 더한다.
- 물고기마다 개성이 느껴지고, 사용자 인터랙션에 반응한다.

## 의존성

- S-005 (물고기 움직임)이 먼저 구현되어 있어야 한다.
- 본 스펙은 S-005의 이동 루프와 물고기 데이터 구조를 확장하는 형태로 동작한다.

## 범위

- 포함할 것:
  - 방향 전환 시 곡선 보간 (부드러운 회전)
  - 사인파 기반 상하 흔들림 (헤엄치는 느낌)
  - 행동 상태 머신 (`cruising` / `idle` / `dart` / `wander`)
  - 개체별 파라미터 차이 (속도 배수, 활동성, 선호 깊이)
  - 마우스 커서 회피 반응
  - 이동 벡터 각도에 맞춘 미세 회전 (몸 기울임)
- 제외할 것:
  - 군집 이동 (boids)
  - 물고기끼리 충돌/상호작용
  - 먹이 추적 (S-006에서 처리)
  - 스프라이트 시퀀스 애니메이션 (별도 스펙으로 분리 가능)
  - 그림자/모션 트레일 등 환경 시각 효과

## 사용자 흐름

1. 사용자가 어항 화면을 본다.
2. 물고기가 부드럽게 방향을 바꾸며 헤엄친다.
3. 어떤 물고기는 빠르게 움직이고, 어떤 물고기는 자주 멈춰서 떠 있다.
4. 사용자가 마우스를 어항 위로 가져가면 가까운 물고기가 빠르게 도망간다.
5. 시간이 지나면 물고기는 다시 평소 행동으로 돌아간다.

## UI/상태 요구사항

- 필요한 화면 요소:
  - 어항 영역 (S-005와 동일)
  - 마우스 위치 추적 (어항 영역 내부 좌표 기준)
- 필요한 상태 (행동 상태 머신):
  - `cruising`: 중간 속도, 완만한 방향 변화 (기본 60%)
  - `idle`: 거의 정지, 제자리 미세 흔들림 (20%)
  - `dart`: 짧은 시간 급가속 (10%, 마우스 회피 시에도 사용)
  - `wander`: 큰 각도 방향 전환 (10%)
- 오류 또는 빈 상태:
  - 마우스가 어항 밖에 있을 때 회피 로직이 동작하지 않는다.
  - 행동 상태 전환이 실패해도 기본 `cruising`으로 폴백된다.

## 행동 요구사항

### 상태 전환 규칙

- 매 3초마다 확률 기반으로 다음 상태를 선택한다 (위 비율 기준).
- `dart`는 최대 0.8초 후 자동으로 `cruising`으로 복귀한다.
- 마우스가 물고기 반경 80px 이내로 진입하면 즉시 `dart` 상태로 강제 전환하고, 마우스 반대 방향으로 도망간다.

### 곡선 보간

- 방향 전환 시 목표 방향으로 0.5초에 걸쳐 lerp 보간한다.
- 보간 진행 중인 동안 상태는 `turning`으로 표기 (S-005의 `turning` 상태가 여기서 의미를 가진다).

### 사인파 상하 흔들림

- 기본 위치에 `sin(time × frequency) × amplitude`를 더한다.
- `frequency`: 2~4Hz (개체별 랜덤)
- `amplitude`: 2~5px (개체별 랜덤)

### 몸 기울임

- 이동 벡터의 y축 성분 비율에 따라 ±15° 이내로 이미지를 회전시킨다.

## 개체별 파라미터

물고기마다 생성 시 아래 값을 랜덤하게 할당한다.

| 파라미터 | 범위 | 설명 |
|---------|------|------|
| `speedMultiplier` | 0.7 ~ 1.3 | S-005 기본 속도에 곱해지는 배수 |
| `idleBias` | 0.0 ~ 0.4 | `idle` 상태 추가 확률 (활동성 낮을수록 큼) |
| `preferredDepth` | top / middle / bottom | 선호하는 수직 영역 (해당 영역으로 약하게 끌림) |
| `wavingFrequency` | 2 ~ 4 | 상하 흔들림 주파수(Hz) |
| `wavingAmplitude` | 2 ~ 5 | 상하 흔들림 진폭(px) |

## 구현 메모

- 관련 파일:
  - `src/features/fish-movement/fishPhysics.js` — 보간/사인파 적용
  - `src/features/fish-movement/fishBehavior.js` — 행동 상태 머신 (신규)
  - `src/features/fish-movement/mouseInteraction.js` — 마우스 회피 (신규)
- 행동 상태 머신은 S-005의 이동 루프와 분리하여 매 프레임 상태별 파라미터를 공급하는 구조로 만든다.
- 개체별 파라미터는 물고기 생성(S-004) 시 같이 할당하거나, 본 스펙 도입 시 기존 물고기 데이터에 마이그레이션한다.

## 검증 기준

- [ ] 물고기가 방향 전환 시 각지지 않고 부드럽게 회전한다.
- [ ] 물고기마다 속도가 눈에 띄게 다르게 보인다.
- [ ] 일부 물고기는 자주 멈춰서 떠 있고, 일부는 활발히 움직인다.
- [ ] 상하 흔들림이 자연스럽게 적용된다.
- [ ] 마우스를 어항 위로 가져가면 가까운 물고기가 도망간다.
- [ ] `dart` 상태가 0.8초 이내에 정상적으로 복귀된다.
- [ ] 이동 방향에 따라 몸이 살짝 기울어진다.
- [ ] 물고기 10마리 기준 60fps를 유지한다.
- [ ] 브라우저 콘솔 오류가 없다.
- [ ] `npm run build`가 통과한다.
